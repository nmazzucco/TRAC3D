CER_GOB Harvesting-Intensity Model Report

Random Forest prediction of working time, harvested stems, and estimated grain output from 3D surface texture variables.

1. Purpose of the script

The CER_GOB.R script models harvesting intensity using experimental observations and applies the trained model to archaeological specimens. Experimental rows are identified by CAT == 1, while archaeological rows are identified by CAT == 2.

The model predicts WORKING_TIME directly from selected 3D surface texture variables. Predicted working time is then converted into harvested stems and estimated grain output.

2. Folder structure

The analysis is designed to run from inside the TRAC3D/CER_GOB directory.

Input file location:

The input file must be located at CER_GOB/RAWDATA/RAWDATA.xlsx.

Generated CSV files, PNG figures, and the trained model are saved in CER_GOB/OUT.

3. Required input columns

The Excel file must contain at least the following columns:

ColumnRole
CATDefines the analytical group: 1 for experimental training data and 2 for archaeological data.
WORKING_TIMEObserved working time for the experimental training data.
TOOLTool identifier used for final aggregation.

Optional columns such as ID and NAME are preserved in the subarea-level output when present.

4. Predictor variables

The script uses a manually selected set of 3D surface texture variables:

Vmc, Sa, Sk, Vvc, Vvv, Smr1, Smr2, Spk, Svk, Sq, Sz, Vm, Vv, Spc, Spd

If one or more predictors are absent from the dataset, the script issues a warning and uses the available predictors.

5. Model workflow

  1. Load RAWDATA/RAWDATA.xlsx.
  2. Remove empty rows and constant columns.
  3. Convert selected numeric-like text columns to numeric values.
  4. Split the dataset into training data (CAT == 1) and archaeological data (CAT == 2).
  5. Train a Random Forest regression model to predict WORKING_TIME.
  6. Apply the model to archaeological rows.
  7. Clamp archaeological predictions to the observed experimental working-time range.
  8. Convert predicted hours into harvested stems using 3797.5 stems per hour.
  9. Aggregate results by TOOL.
  10. Estimate grain output using 0.30 g per harvested stem.
